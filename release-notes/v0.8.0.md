## 新しく入れる場合 / New install

`XIVToolHub-Setup.exe` をダウンロードして実行してください。管理者の権限は要りません。
Download and run `XIVToolHub-Setup.exe` (no admin rights needed).

すでに使っている場合は、XIVToolHub を起動すると更新するか聞かれます（`XIVToolHub-win-x64.zip` は自動更新用です）。
Existing users are offered the update on startup (`XIVToolHub-win-x64.zip` is used for self-update).

## 変更点 / Changes

- インストーラー（Setup.exe）を追加しました。スタートメニュー・デスクトップのショートカットと、「アプリと機能」からのアンインストールに対応します。
  Added an installer with shortcuts and uninstall support.
- ツールを選んだとき、まだ入っていない必要なツールを「同時にインストールしますか？」と確認するようにしました。ACT を選ぶと、一緒に使うプラグインも入れるか確認します。
  Selecting a tool now asks whether to install its required tools too.
- 前提のソフト（VC++ ランタイム・.NET Framework 4.8・XIVLauncher）を、ツールのインストールのときに調べ、無ければ確認してから公式の配布元から入れるようにしました。
  Prerequisites are detected and installed from official sources after confirmation.
- 初めて使うときの案内を表示するようにしました。
  Added first-run guidance.
- 同梱のツールはすべて公開リポジトリから取得するので、GitHub トークンは任意になりました。
  All bundled tools come from public repositories; a GitHub token is now optional.
